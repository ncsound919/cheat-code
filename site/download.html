Install in three steps

  1. Open the download on the phone. Chrome will warn about files from outside Play — choose Download anyway.
  2. Tap the file, then allow Install unknown apps for Chrome or your file manager.
  3. Android asks once more; tap Install. Updates install over the top and keep your ledger.

What happens when you open it

  1. The first launch seeds a sample board and labels it as samples. It does not pretend synthetic data is live.
  2. Add your prop-price key and box-score key under Live data. The first successful sync retires the fixtures.
  3. The app runs an initial sandbox round and starts the paper ledger. Every priced row is recorded, win or lose.

Want to understand the rules before installing? Read the manual first — it is free and needs no download.

Checking what you got

Every build is signed by the same key, so an update only installs over a genuine copy. If you want to check the file itself, compare its SHA-256 with the value above: on a computer, sha256sum cheat-code.apk; on Windows, certutil -hashfile cheat-code.apk SHA256.
